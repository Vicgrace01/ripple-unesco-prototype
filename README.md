# RIPPLE: Experience the Future Before You Believe It

![RIPPLE Prototype](https://via.placeholder.com/1200x600.png?text=RIPPLE:+Consequence-Based+Media+Literacy)

**RIPPLE** is an AI-powered narrative investigation game designed to teach Media and Information Literacy (MIL). Instead of asking players to simply identify whether a claim is true or false, Ripple challenges them to reconstruct how information influenced decisions, institutions, and communities. 

*This prototype was built for the **UNESCO Youth Hackathon 2026** under the theme: "Play Your Part: Youth Designing the Future of Media and Information Literacy."*

## 🎯 The Problem We Solve
Young people increasingly learn and make decisions using information gathered from social media and generative AI. Traditional MIL initiatives successfully teach concepts like source evaluation, but many learners struggle to transfer those lessons into everyday behavior. **Ripple addresses this gap by making information decisions tangible, memorable, and interactive.**

## ✨ Core Features
- **Observe the Consequence:** Explore a living world already affected by an information failure (e.g., a collapsed bridge).
- **Interactive Evidence Board:** Gather diverse evidence and connect claims, timelines, and supporting documents.
- **AI Investigator:** Collaborate with an AI that asks critical questions instead of providing easy answers, promoting responsible AI use.
- **Rewrite Reality:** Replay decisions using verified information to create a different outcome.
